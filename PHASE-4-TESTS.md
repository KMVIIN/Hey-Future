# Future 3.1 — Calendar & Workflow Management Tests

## Calendar Day View
- Open Calendar from the sidebar; it should jump to the Day Planner.
- Click any day in the 7-day strip; existing event/task/reminder items for that date appear below.
- Empty days clearly show that the day is free and offer + Add item.
- Add Event, Task, and Reminder items; refresh the browser and confirm they remain saved.
- Edit an item title/date/type and confirm it moves to the correct day.
- Mark an item Done and delete an item.

## Workflows
- Create a workflow through Ask Future.
- Edit its title/summary.
- Pause and resume it.
- Delete it; any associated approval should also disappear.
- Refresh and confirm workflows/approvals remain saved.

## Ask Future
- Desktop composer should be visibly wider with a taller text area.
- Mobile composer should remain usable without horizontal scrolling.
