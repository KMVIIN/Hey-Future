# Future 4.4 — Search, Email, Map & Accounting

## Main dashboard
- Search & Discover remains on the dashboard.
- The former large Map & Places slot is replaced with Outlook & Inbox.
- Map & Places is now a compact launcher beside Ask Future and opens the large map workspace only when needed.
- Ask Future chat is resized to a normal vertical messenger-style window on desktop.

## Free Search & Discover
- Free/guest search no longer depends on OpenAI.
- The server now attempts ordinary public web results from Bing RSS and DuckDuckGo HTML search, with Wikipedia as a fallback/supplement.
- Results remain inside Future and include clickable source links.
- Paid accounts can still use OpenAI web research when configured and within plan limits.

## Accounting
- Added Accounting to the sidebar.
- Added a simple income/expense ledger with date, category, description and amount.
- Shows income, expense and balance totals.
- Stores entries locally in the browser and exports CSV.

## Version
- package.json: 0.4.4
